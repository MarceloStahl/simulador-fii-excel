# 📊 Simulador de Investimentos em Fundos Imobiliários (FII)

## 📌 Sobre o projeto

Este projeto foi desenvolvido como parte de um desafio prático de Excel, com o objetivo de criar uma ferramenta para simular a evolução de investimentos em Fundos Imobiliários (FIIs).

A planilha permite informar os principais parâmetros de uma estratégia de investimento e visualizar automaticamente o patrimônio projetado e os dividendos estimados ao longo do tempo.

> **Aviso:** este projeto possui finalidade educacional. As taxas utilizadas são hipóteses para simulação e não representam garantia de rentabilidade futura.

---

## 🎯 Objetivos

- Aplicar conceitos de Excel em uma situação prática de investimentos;
- Criar uma ferramenta de simulação financeira;
- Utilizar fórmulas para automatizar cálculos;
- Projetar a evolução do patrimônio ao longo dos meses;
- Estimar dividendos mensais e acumulados;
- Utilizar gráficos para facilitar a interpretação dos resultados;
- Documentar o projeto utilizando GitHub.

---

## 🧮 Parâmetros da simulação

O usuário pode alterar os seguintes dados:

| Parâmetro | Descrição |
|---|---|
| Investimento inicial | Valor aplicado no início da simulação |
| Aporte mensal | Valor investido mensalmente |
| Prazo | Quantidade de meses da simulação |
| Rentabilidade mensal | Taxa mensal estimada para evolução do patrimônio |
| Dividend Yield mensal | Percentual mensal utilizado para estimar os dividendos |

---

## 📈 Resultados apresentados

A ferramenta calcula automaticamente:

- **Total investido**
- **Patrimônio acumulado**
- **Dividendos mensais**
- **Dividendos acumulados**
- **Rendimento sobre o total investido**

Além disso, a planilha apresenta:

- Gráfico de evolução do patrimônio;
- Gráfico de dividendos mensais;
- Tabela de projeção mês a mês.

## 🚀 Como utilizar

1. Baixe o arquivo `Simulador_FII_Novo.xlsx`;
2. Abra o arquivo no Microsoft Excel;
3. Acesse a aba **Simulador**;
4. Altere os valores destacados para os parâmetros desejados;
5. Observe os resultados calculados automaticamente;
6. Analise a evolução do patrimônio e dos dividendos nos gráficos.

### Exemplo inicial

A planilha foi configurada inicialmente com:

- Investimento inicial: **R$ 10.000,00**
- Aporte mensal: **R$ 1.000,00**
- Prazo: **60 meses**
- Rentabilidade mensal estimada: **0,80%**
- Dividend Yield mensal estimado: **0,90%**

Esses valores podem ser alterados livremente para testar diferentes cenários.
